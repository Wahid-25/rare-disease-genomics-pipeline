References and source policy
============================

The full manuscript preserves the project’s tool and resource names, scientific statements and source notes. Before formal academic submission, the reference list should be completed using the citation style required by the university or supervisor.

Primary sources should be preferred in this order:

#. Original research paper or technical standard.
#. Official tool documentation.
#. Official database documentation.
#. Peer-reviewed review article.
#. Educational website.
#. Informal tutorial or blog.

Core resources requiring formal citation include bcftools, Ensembl VEP, SnpEff, ClinVar, ClinGen, SpliceAI, Gene2Phenotype, HPO, MONDO, ClinPGx, CPIC, AnnotSV, ClassifyCNV, ISV-CNV, Apptainer and the VCF specification.
